# 这轮实验真正改善了什么

本轮有可核验的正向结果：在同一批新测试题上，新增问题相关证据特征的 MLP，比使用原 20 维特征、同样扩展训练数据的 MLP，多答对 5 题，同时节省更多输入 token。预定的有害接受比例目标仍未达标，因此不能称为已经可靠控制压缩风险的成品。

所有数据均来自 `results/metrics.json`；最终测试包含 160 个独立来源、32 个留出的措辞／布局家族。主 MLP 种子固定为 520。模型与门槛在测试回答生成前已冻结。

| 同一新测试集上的策略 | 答对题数/160 | 输入 token 节省 | 原文正确、采用压缩后答错 |
|---|---:|---:|---:|
| 原文 | 111 | 0% | 0 |
| 固定保留 60% 上下文 | 100 | 35.57% | 25 |
| 原 20 维特征 MLP，使用扩展训练数据 | 109 | 20.68% | 14 |
| 新 38 维特征 MLP，使用相同扩展训练数据 | 114 | 25.94% | 11 |

新特征方案相比旧特征方案，准确率从 109/160 提升到 114/160，输入 token 节省增加约 5.26 个百分点。这是本轮最清晰的质量与效率同时改善的对照。两种方案使用相同训练／验证数据、网络层宽、主种子和验证选择规则，但各自的早停轮次和验证门槛不同；它比较的是完整特征方案，不能把收益归因于某一个特征。

相比固定保留 60% 的策略，新版多答对 14 题，有害接受从 25 次降到 11 次；同时 token 节省从 35.57% 降至 25.94%。这里存在质量与压缩程度的取舍，不能说二者计算预算完全相同。

原始 V1 冻结模型在这批新测试题上答对 93/160，节省 59.88%，有害接受 32 次。新版答对更多、误接收更少，同时采取了更保守的压缩；这同样不是两项指标都占优的比较。

## 哪些结论还不能说

- 预定目标是 token 节省至少 20%、准确率相对原文下降不超过 2.5 个百分点、有害接受占全部任务不超过 5%。新版达到前两项，第三项为 11/160=6.875%，未达到。
- 新版相对原文只多答对 3 题，准确率差的模板组 bootstrap 95% 区间为 [-5.625, +10.0] 个百分点，不能宣称已证明准确率提升。
- 新版对旧特征方案的逐题 McNemar p≈0.227；组 bootstrap 的正区间也不足以支持普遍优越结论。样本量、模板相关性和多重比较都限制统计解释。
- 较长文本子集仍有退化：新版 53/82 正确，原文 55/82 正确；输入 token 节省为 20.67%。
- 八类高层结构均已进入开发数据。本轮验证的是新来源与留出措辞家族，不是完全未见结构的分布外泛化。所有内容为合成英文事实，回答模型只有一个小型本地模型。

完整策略、随机种子、消融、置信区间、原始回答和失败案例均保留在项目中。课堂报告可以据此陈述：问题相关证据特征带来了更好的观测权衡，但验证集上的风险约束尚不能直接保证新测试集的风险水平。
