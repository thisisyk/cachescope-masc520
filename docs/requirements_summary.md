# MASC 520 final project deliverables

The supplied course syllabus permits a project that uses deep learning, with teams of at most two members. It asks for a dedicated public GitHub repository containing documented code, datasets and a README; an approximately ten-minute presentation covering the problem, development, solution and outcomes; and an IEEE-style report, typically four to six pages of main text plus appendices.

The report should explain motivation, assumptions, methodology, experimental results, observations, conclusions and references. The syllabus allows AI assistance when it is fully disclosed and properly cited. It does not specify a minimum accuracy score or require that every experimental hypothesis succeed.

This repository supplies the experimental code, synthetic datasets, models, recorded responses, audits and result documentation. Final report artifacts are stored in `reports/`. A presentation is a separate course deliverable. This file is a short paraphrase of the supplied requirements, not the original syllabus or a new grading rule. No unverified final deadline is asserted.
